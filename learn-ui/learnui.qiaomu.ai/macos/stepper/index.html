Stepper 步进器 macos

The compact up-and-down arrow pair used to increment or decrement a value

一对紧凑的上下箭头，用来递增或递减数值

also called也叫
stepper control, stepper arrows, numeric stepper, incrementer步进控件、步进箭头、数字步进器、增减器
If you called it…如果你管它叫……
  • “the tiny up and down arrows beside a number field”「数字框旁边那对小上下箭头」
  • “little control that increases or decreases a value”「能增减数值的小控件」
  • “stacked arrow buttons next to a numeric input”「数字输入框旁边上下叠着的箭头按钮」
  • “small plus minus style control for changing a number”「调数字用的那种加减小控件」
  • “spinner arrows for adjusting a value one step at a time”「一步一步调数值的微调箭头」

Debug prompt — when it misbehaves调试 Prompt —— 当它不听话时

Debug my macOS stepper (NSStepper, SwiftUI Stepper). Rule out: the stepper and its text field not bound to the same value so they drift; valueWraps looping from max back to min; autorepeat firing continuously while held when single steps were expected; a number formatter clamping or rejecting the value the stepper just set. The symptom:
