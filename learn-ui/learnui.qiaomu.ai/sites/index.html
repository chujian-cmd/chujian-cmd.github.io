克制的企业级汽车设计：白色画布（#ffffff）被深海军蓝首屏色带（#1a2129）打断，唯一的宝马企业蓝（#1c69d4）用在每个 0px 圆角矩形 CTA 上，BMW Type Next Latin 以 700 字重标题对比 Light 300 细体正文。

BMW M 宝马 M（BMW M） Automotive

Motorsport minimalism on a true-black canvas (#000000): white uppercase BMW Type Next Latin headlines at weight 700, hairline dividers, and full-bleed track photography doing all the decoration. The M tricolor stripe (#0066b1 → #1c69d4 → #e22718) appears only as a brand marker — never as a button fill or background.

赛车工程的极简主义：纯黑画布（#000000）上排布白色大写标题（BMW Type Next Latin，700 字重），发丝线分隔，全幅赛道摄影承担全部装饰。M 三色条纹（#0066b1 → #1c69d4 → #e22718）只作品牌标记 —— 从不用作按钮填充或背景。

Bugatti 布加迪（Bugatti） Automotive

The most austere site in luxury automotive: a pure-black canvas (#000000), white uppercase display type with 2–4px letter-spacing, and zero decoration — the only non-monochrome token anywhere is a rare ice-blue link (#c3d9f3). Three custom faces (Bugatti Display, serif Bugatti Text Regular, Bugatti Monospace) plus full-bleed photography do everything.

豪华汽车里最克制的界面：纯黑画布（#000000）、白色大写标题配 2–4px 字距，零装饰 —— 全站唯一的非黑白 token 是罕见的冰蓝链接（#c3d9f3）。三款定制字体（Bugatti Display、衬线的 Bugatti Text Regular、Bugatti Monospace）加上全幅摄影，就是全部。

Ferrari 法拉利（Ferrari） Automotive

Cinematic editorial luxury: a warm near-black canvas (#181818), pure-white FerrariSans display type at weight 500 with negative tracking, and one scarce accent — Rosso Corsa (#da291c) — reserved for primary CTAs, the Cavallino mark, and F1 race numbers. Full-bleed photography is the chrome.

电影级的编辑式豪华：微暖的近黑画布（#181818）、纯白 FerrariSans 标题（500 字重配负字距），以及唯一的稀缺强调色 Rosso Corsa（#da291c）—— 只给主按钮、跃马车标和 F1 车号。全幅摄影就是界面铬件。

Lamborghini 兰博基尼（Lamborghini） Automotive

Nocturnal theater: an uncompromising true-black canvas (#000000) where white LamboType headlines shout in uppercase at up to 120px, and a single accent — Lamborghini Gold (#FFC000) — ignites only on primary CTA buttons. Elevation comes from layering lighter grays over black, never from shadows.

夜间剧场：毫不妥协的纯黑画布（#000000），白色 LamboType 大写标题以最大 120px 喊出来，唯一的强调色兰博基尼金（#FFC000）只在主按钮上点燃。纵深感靠在黑色上叠更亮的灰色，从不用投影。

Renault 雷诺（Renault） Automotive

High-contrast mass-market catalogue: a white canvas for browsing that flips to full-bleed black (#000000) for storytelling bands, punctuated by a single Sunlight Yellow accent (#ffed00) on primary CTAs and "NEW" badges. Everything is set in Renault's proprietary NouvelR at weight 700 with a tight 0.95 line-height.

高对比的大众市场目录风：浏览用白色画布，讲故事时整幅切换为黑色（#000000）区块，再用唯一的日光黄（#ffed00）点缀主按钮和「NEW」徽章。全站只用雷诺自有的 NouvelR 字体，700 字重配 0.95 紧凑行高。

Tesla 特斯拉（Tesla） Automotive

Radical subtraction: a pure-white canvas (#FFFFFF), one chromatic color — Electric Blue (#3E6AE1) — spent only on primary CTAs, and full-viewport photography carrying all emotional weight. Universal Sans (Display + Text) at weights 400–500 keeps every screen quiet, with no shadows, gradients, or borders.

极致的减法：纯白画布（#FFFFFF），唯一的彩色电光蓝（#3E6AE1）只花在主按钮上，全视口摄影承担全部情绪重量。Universal Sans（Display + Text）只用 400–500 字重，没有阴影、渐变和边框，每屏都安静。

Dell (1996) 戴尔 1996 年版（Dell） Retro Web · 1990s

Catalog-era enterprise web preserved in amber: the entire page sits inside a literal 8px black frame (#000000), each product line gets a flat ribbon-card tint (sage #b3bd95, salmon #d77a7a, periwinkle #8c9ae0), Arial Black 900 display type tops Times New Roman body copy, and all decoration is hand-cut GIF stickers.

目录时代企业网页的活化石：整个页面套在一个 8px 纯黑相框（#000000）里，每条产品线配一个扁平色块丝带卡（灰绿 #b3bd95、鲑鱼粉 #d77a7a、长春花蓝 #8c9ae0），Arial Black 900 大标题压着 Times New Roman 正文，装饰全是手工剪切的 GIF 贴纸。

Nintendo.com (2001) 任天堂官网 2001 年版（Nintendo.com） Retro Web · 1990s

Y2K console-hardware chrome: the page is assembled from brushed-periwinkle (#7a8aba) beveled metal plates, a carbon-navy (#21242e) halftone-dotted command bar carries navigation, warm orange (#f68d1f) is rationed to wayfinding, and Arial Black hero wordmarks are outlined like game box art.

千禧年游戏机面板美学：整个页面由拉丝长春花蓝（#7a8aba）斜角金属板拼装而成，碳深蓝（#21242e）半调圆点纹理的指令栏承担导航，暖橙色（#f68d1f）只用于指路，Arial Black 大标题描边加硬阴影，像游戏盒封面。
