kami 折纸模拟器 —— 离线版说明
================================

这是 https://kami.maxwase.eu/ 的完整镜像，2026-11-14 爬取。
包含全部 JS / CSS / 图片（含 textures 里的纸纹、木纹和横幅图）/ 图标，
一共 80 多个文件，约 4.5 MB。断网也能玩。

不要直接双击 index.html 打开！
这个站用的是绝对路径和模块脚本，直接用 file:// 打开浏览器会拦截，页面会白屏。
要用一个本地小服务器把这个文件夹“供”出来，再用浏览器访问 localhost。

--------------------------------
电脑上玩（Windows / Mac / Linux）
--------------------------------
1. 解压 zip，进到 kami-offline 文件夹。
2. Windows：双击 start-windows.bat
Mac / Linux：在这个文件夹里打开终端，运行 sh start.sh
（需要装有 Python 3；没有的话也可以用任何静态服务器软件指向这个文件夹）
3. 浏览器打开 http://localhost:8899 就能玩，全程不用联网。

--------------------------------
安卓手机上玩
--------------------------------
方法一（Termux）：
1. 把解压后的文件夹放进手机存储。
2. Termux 里进入这个文件夹，运行： python -m http.server 8899
（Termux 里先 pkg install python 装一下 Python）
3. 手机 Chrome 打开 http://localhost:8899

方法二：装一个“本地服务器”类的 App，把网站根目录选成这个文件夹，
启动后按 App 给的 localhost 地址在浏览器打开，效果一样。

--------------------------------
说明
--------------------------------
- kami 本来就会根据设备的姿势/铰链角度折纸（折叠屏、笔记本合盖），
在普通手机/电脑上也可以用手指/鼠标手动折、翻面、换纸张大小和颜色、撤销。
