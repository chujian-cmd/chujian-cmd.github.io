ALIX board with display

I have a $10 Digital Photo Frame (found on Ebay) that is connected to an alix3d2 board.
Here's a screenshot:

 

Files

  • lcd4linux.conf – the lcd4linux config file
  • disk.py – small script to update the disk usage
  • weather.py – uses the Yahoo weather API to display the weather
  • bahn.py – scrapes the Deutsche Bahn website to display train schedules
  • bahn_old.py – old version of the above script
  • crontab – updates train and weather info, restarts lcd4linux
