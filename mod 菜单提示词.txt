---

提示词：通用 H5 Mod 调试面板 (Mod Panel)

---

你的角色：资深前端开发工程师。

任务：生成一个独立的、可拖动的 H5 悬浮调试面板，用于网页游戏开发调试。

输出要求：

· 只输出可插入目标页面 </body> 标签之前的代码块。
· 不输出 <!DOCTYPE>、<html>、<head>、<body> 等文档结构标签。
· 所有样式和逻辑都包含在单个 <script> 标签中，样式通过 document.createElement('style') 动态注入。

---

功能规格：

1. 入口与界面
   · 右下角圆形悬浮按钮，点击展开/收起主菜单。
   · 主菜单为毛玻璃卡片面板，标题栏可拖动。
2. 核心标签页
   · 数值：输入框 + 读取/写入按钮，修改应用全局变量。
   · 加速：倍率输入 + 开关，控制主循环速度。
   · 解锁：预设快捷操作按钮。
   · 日志：拦截并显示 console 日志和网络请求。
3. 技术要求
   · 纯原生，无第三方依赖。
   · 样式通过 JS 动态创建 style 元素注入，使用 .mod- 类名前缀隔离。
   · z-index: 9999999999。
   · 日志保留最近 50 条。
   · IIFE 包裹，避免污染全局。

---

输出格式：
<script>
// 1. 创建 style 元素，写入所有 CSS
// 2. 创建 FAB 按钮和面板 DOM
// 3. 实现拖动、标签页切换、数值读写、加速、解锁、日志拦截等功能
// 4. 所有逻辑在 IIFE 内执行
</script>
