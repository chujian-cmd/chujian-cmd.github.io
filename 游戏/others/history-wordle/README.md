# 历史 Wordle

猜一个**历史事件或历史人物**（中国史 + 世界史），共 6 次机会，**字数不固定**
（2~9 个字，棋盘每行列数就是答案字数）。

- 🟩 绿色：这个字在答案里，位置正确
- 🟨 黄色：这个字在答案里，但位置不对
- ⬜ 灰色：答案里没有这个字

## 打开方式

**直接双击 `index.html` 就能玩。**

这是一个单文件游戏：界面样式、游戏逻辑、371 条历史题库（人物 + 事件）、
拼音数据全部打包在一个 HTML 文件里，离线可用，无需安装。

## 玩法流程

1. **开局**：棋盘下方用琥珀色标签标明答案是**人物**还是**事件**，并显示
   **线索1**（人物：类别；事件：时间）。
2. **输入**：在输入框打拼音（如 `ji`），候选字自动出现，点选上屏；或点底部
   💡 提示按钮主动要线索。
3. **猜错**：自动弹出嘲讽弹窗（「雑魚ざこ！」「就这？」等随机标题）。
   点 **💡 可恶的雌小鬼** 放出下一条线索，点 **我是猛男口牙** 继续作答。
4. **线索链**（由模糊到精准，共 5 条）：
   - 事件题：时间 → 人物 → 地点 → 影响 → 雑魚就是雑魚（一句话概括）
   - 人物题：类别 → 身份 → 成就 → 特征 → 雑魚就是雑魚（一句话概括）
   **看提示消耗当前尝试**：每看一条提示，当前那次尝试直接判定失败
   （该行标记 ✕），输入次数 -1，猜词数 +1。
   只剩最后一次尝试时，提示按钮变为「雑魚认证」认输，不再提供线索。
   5 条全部放完后，弹窗会变成「雑魚认证」认输按钮，点击显示答案、本题计为失败；
   「测测need学」模式下 4 秒后自动进入下一题。
5. **猜对**：弹出激励弹窗（随机鼓励语 + 分档评价：一次猜中「天选之人」、
   压线通关「雑魚认证通过」等）：
   - 「测测need学」模式：**自动清除本题并进入下一题**（3.5 秒后自动开始，
     可点「立即下一题」跳过等待；点「查看统计」会**立即进入下一题**并保留统计弹窗）
    - 「每日」模式：**就这样吧** / **测测need学** / **查看统计**

底部「换一题」按钮下方还有一个常驻的 **📊 查看统计** 按钮，随时可以打开统计面板。
6. **6 次用完**：显示答案和分类，统计弹窗只展示数据；想继续玩可点底部
   「换一题」或顶栏模式按钮。

## 模式与换题

- **每日**：每天同一道题，适合打卡，没有换题按钮。
  每日题**完成后当天锁定**，无法重开（防止重复刷正确率），次日 0 点解锁。
- **测测need学**：每局随机换题；底部有 **🔄 换一题** 按钮，点击后需先确认
  **我是雑魚** 才会换题，选 **我才不是雑魚** 则继续当前作答；题目已完成
  （输赢已定）时点击直接换题，无需确认；中途放弃时，嘲讽内容与已用尝试次数
  挂钩（试得越少越惨，就差最后一步时还会惋惜）。

## 小提示

- 猜测允许任意长度的汉字组合，答案从内置历史题库中抽取。
- 每天 0 点后「每日」自动换题。
- 统计面板包含：局数、胜率、连胜、**最佳**（最大连胜），以及 **回答错误**（6 次用完）和
  **看答案**（点「雑魚认证」认输）两个失败分类。
- **连胜与最佳在所有模式通用**：连胜 = 连续答对的局数（输了清零），
  最佳 = 历史最大连胜。
- **胜率段位绰号**（每 10% 一档）：纯雑魚 → 菜鸡本鸡 → 蒙题苦手 →
  半吊子选手 → 五五开戦士 → 及格猛男 → 历史熟手 → 学霸预备役 →
  行走百科 → 历史大师 → 天选之人。
- 统计面板顶部会记录**上一题**的答案、分类和结果（第几次猜中 / 看答案认输 /
  未猜中），新题开始后依然保留，可随时回看。
- 统计面板可点**生成分享图**生成一张战绩卡片（含绰号、胜率、连胜、最佳），
  下载后可直接发给好友；没完成对局时也能生成纯统计卡片。
- 统计与连胜记录保存在浏览器 localStorage 中。
