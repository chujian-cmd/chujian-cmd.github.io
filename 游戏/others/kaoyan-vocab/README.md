# 研词 · 考研背单词

一个纯前端、开箱即用的考研英语背单词网站，包含 **词义辨析、真题例句、英美发音** 三大核心功能。

## 如何运行

无需安装任何依赖，直接双击 `index.html` 用 Chrome / Edge 打开即可。

> 发音功能依赖浏览器的语音合成（Web Speech API），Chrome / Edge 效果最佳。

### 单文件版（推荐用于手机）

`研词-考研背单词-单文件版.html` 将页面、样式和全部词汇数据打包成了一个文件，
直接用手机浏览器打开（或通过微信/QQ 发送后在浏览器中打开）即可使用，
也可上传到任意静态托管（GitHub Pages、Netlify 等）生成在线网址。

## 功能一览

| 页面 | 功能 |
| --- | --- |
| 背单词 | 单词卡片（音标、释义、词义辨析、常考搭配、真题例句），美音/英音朗读，认识/模糊/不认识标记，隐藏释义自测，随机打乱，键盘快捷键 |
| 词义辨析 | 287 组考研易混词辨析，点击展开查看细微差别，可一键跳转到对应单词卡片 |
| 真题例句 | 按年份筛选（2003–2020 考研英语一/二真题），例句中目标词高亮，一键听美音/英音，可切换中文译文 |
| 自测 | 三种题型：英译中、中译英、真题选词（真题句子填空），即时对错反馈与答案解析 |
| 收藏 | 收藏重点单词，集中复习 |
| 进度 | 掌握分布（已掌握/模糊/不认识）、自测正确率、真题例句年份覆盖统计 |

## 键盘快捷键（背单词页）

- `→` / `←`：下一个 / 上一个
- `1` / `2` / `3`：不认识 / 模糊 / 认识
- `F`：收藏 / 取消收藏
- `空格`：显示 / 隐藏释义

## 数据说明

- 内置 287 个考研核心词，全部配有英式、美式音标与真题例句。
- 真题例句均出自历年考研英语（一/二）真题的阅读与翻译部分，标注了年份与题型来源，并附参考译文。
- 词义辨析覆盖考研阅读中最常考的易混词，如 insist / persist / consist、refrain / restrain / restrict、vague / ambiguous / obscure 等。
- 学习进度、收藏、测验记录保存在浏览器本地（localStorage），不会上传。
