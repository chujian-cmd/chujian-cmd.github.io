竞技场枪战 · Arena Gunfight 项目文档

本文档是对项目目录下全部 HTML 文件的整理说明，涵盖 2D / 3D 两个分支的演进过程、玩法机制、操作方式、可调参数与作弊系统。

---

一、项目简介

竞技场枪战是一款可直接在浏览器运行的单文件网页游戏。采用 Canvas 2D 与 Three.js 两种实现路线，围绕“在封闭竞技场中生存 10 波敌人”的核心循环展开：

· 移动 + 瞄准 + 射击的第三人称俯视射击手感
· 三种武器（手枪 / 步枪 / 霰弹枪）带弹匣、换弹、后坐力、散布
· 三类敌人（冲锋兵 / 射手 / 精英）各自拥有近战或远程 AI
· 冲刺闪避、血包回血、波次递进
· 同时适配 PC 键鼠 与 移动端触屏

全部资源内联在单个 .html 中，无外部依赖（3D 版仅通过 importmap 从 CDN 加载 three@0.160.0）。

四、核心机制

4.1 波次系统

· 共 10 波，每波敌人数量、血量、伤害、速度按公式递进
· 敌人类型随波次解锁：第 2 波起出现射手，第 4 波起出现精英
· 一波清空后进入 3 秒间隔，再自动开始下一波
· 全部 10 波清除 → victory；玩家 HP 归零 → gameover

关键参数位于 CFG.wave：

```js
maxWave: 10        // 总波数
hpScale: 0.13      // 每波血量增幅
dmgScale: 0.07     // 每波伤害增幅
spdScale: 0.025    // 每波速度增幅
baseCount: 2       // 第一波基数
perWave: 2         // 每波递增数量
maxCount: 22       // 单波数量上限
intermission: 3.0  // 波次间隔（秒）
```

4.2 武器数据

武器 伤害 射速(秒/发) 弹匣 换弹(s) 散布 弹丸数
手枪 26 0.26 12 1.10 0.035 1
步枪 13 0.085 30 1.70 0.055 1
霰弹枪 11 0.75 6 2.00 0.130 9

· 每种武器独立维护弹药 / 冷却 / 换弹 / 后坐力状态
· 打空自动触发换弹
· 后坐力累积会放大散布，停火后逐渐衰减

4.3 敌人类型

类型 血量 速度 行为
冲锋兵 45 168 近战，看到玩家后直冲，接触造成伤害
射手 60 118 远程，保持距离走位，弹匣打空会换弹
精英 200 92 高血量远程，一次发射 2 发子弹，血量随波次大幅成长

AI 状态机包含 patrol / chase / attack / dodge / reload，并会做视线检测（被障碍物挡住时不会开枪）。

4.4 血包系统（从 (2).html 起）

· 普通敌人 30% 掉落，精英 100% 掉落
· 地面定时刷新（默认每 9 秒，场上最多 6 个）
· 靠近会磁吸（默认 110 单位范围）
· 满血拾取转化为分数；残血拾取回复 25 点

```js
CFG.pickup = {
  dropChance: 0.30, eliteDropChance: 1.00,
  heal: 25, life: 15, scoreBonus: 15,
  spawnInterval: 9, maxOnMap: 6, magnetRange: 110
}
```

4.5 冲刺

· 默认速度 980、持续 0.15 秒、冷却 1.4 秒
· 冲刺期间无视普通加速度，直接按固定方向高速位移
· 冷却圈显示在角色脚下 / 冲刺按钮上

五、3D 版技术要点

5.1 双视角相机

· 第三人称：PerspectiveCamera 在玩家上方 660、后方 560，lookAt 略微前移
· 第一人称：camera.rotation.order = 'YXZ'，用 yaw / pitch 控制，pitch 被限制在 ±0.62 弧度内
· 切换时同步隐藏 / 显示玩家模型，并请求 / 释放指针锁定

5.2 屏幕 → 地面射线

第三人称鼠标瞄准使用 Raycaster 与 y = 0 平面求交：

```js
const groundPlane = new THREE.Plane(new THREE.Vector3(0,1,0), 0);
raycaster.setFromCamera(ndc, camera);
const hit = raycaster.ray.intersectPlane(groundPlane, point);
```

5.3 对象池

· 子弹使用 acquireBullet / releaseBullet 复用 Mesh
· 粒子使用单个 Points + BufferGeometry，每帧写入 Float32Array 并更新 drawRange
· 浮动文字用 CanvasTexture 缓存，相同文本 + 颜色只生成一次

5.4 性能取舍

· 移动端自动关闭阴影、抗锯齿
· pixelRatio 上限 2
· dt 上限 0.05，防止切后台回来跳帧

六、作弊系统

6.1 2D 版 (4).html

按 F8 或点击右上角 ⚙ 打开面板。包含：

· 玩家：当前血量、最大血量、移动速度、冲刺速度 / 时长 / 冷却、碰撞半径、加速平滑
· 武器：三种武器分别调伤害、射速、弹匣、换弹、散布、后坐力、弹速、存活、弹丸数、震动
· 敌人：血量 / 伤害 / 速度倍率，以及三种敌人的基础属性
· 波次：最大波数、首波基数、每波递增、上限、间隔、成长曲线
· 道具：回复量、掉落概率、精英必掉、存活、刷新间隔、上限、磁吸、满血转分
· 相机：平滑、前瞻、前瞻距离、震动衰减
· 开关：无敌、无限弹药、秒杀、无限冲刺、无后坐力、玩家 / 敌人子弹穿墙、敌人不动、敌人不攻击、子弹无限射程
· 快捷：回满血、清屏、跳过本波、重置所有作弊

6.2 3D 版 (6).html / (7).html

· (6).html：单页签面板，覆盖玩家、血包、开关、快捷操作
· (7).html：多页签完整面板，额外支持武器逐项调参、敌人倍率、波次曲线、相机参数（含第一人称眼睛高度 / 灵敏度 / 俯仰上限）

6.3 实验性“作弊数值”分支

3d 版 (3)(4)(5).html 直接把常量改成了极端值，用于快速演示：

```js

mag: 999, reload: 0, fireRate: 0
```

(5).html 还注释掉了子弹与障碍物的碰撞判定，实现穿墙射击。

这些文件不适合作为正式玩法入口，仅供调试 / 演示 / 娱乐。

八、已知注意事项

1. 3D 版依赖 CDN：three@0.160.0 从 unpkg.com 加载，离线环境需自行本地化。
2. 竖屏提示：所有文件在竖屏下会显示“请横屏使用”遮罩，并隐藏游戏画面。
3. 指针锁定限制：浏览器要求用户手势触发 requestPointerLock，因此首次进入第一人称需要点击一次画面。
4. 作弊面板与输入框：在面板输入框内按 F8 仍可关闭面板；Esc 会先让输入框失焦。
5. 数值极端化的版本（(3)(4)(5)）可能导致 UI 显示溢出或渲染异常，属于预期行为。
6. 切后台恢复：主循环对 dt 做了 0.05 秒上限，但长时间切后台仍可能造成一次较大跳变，建议在 visibilitychange 时手动重置 lastT（当前未实现）。
