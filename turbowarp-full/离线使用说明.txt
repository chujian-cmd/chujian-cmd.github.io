TurboWarp 编辑器 —— 离线版说明
================================

这是 https://turbowarp.org 编辑器的完整离线镜像，2026-11-14 爬取。
包含 editor.html、插件设置页（addons/）、全屏页、嵌入页，
以及全部 JS 分块、static 静态资源和图片。断网也能打开编辑器写项目。

不要直接双击 editor.html（file:// 打开）！
编辑器的脚本按网站根路径加载资源，用 file:// 打开会白屏。
要用一个本地小服务器把这个文件夹作为网站根目录供出来：

--------------------------------
电脑上用（Windows / Mac / Linux）
--------------------------------
1. 解压 zip，进到 turbowarp-offline 文件夹。
2. 在这个文件夹里打开终端 / 命令行，运行：
python -m http.server 8899
（需要 Python 3；也可以用任何静态服务器软件指向这个文件夹，
关键是这个文件夹要当“网站根目录”。）
3. 浏览器打开 http://localhost:8899/editor.html
插件设置页是 http://localhost:8899/addons/

--------------------------------
安卓手机上用
--------------------------------
方法一（Termux）：进入这个文件夹，运行 python -m http.server 8899，
然后 Chrome 打开 http://localhost:8899/editor.html
方法二：用“本地服务器”类 App，把根目录选成这个文件夹再打开它给的地址。

--------------------------------
离线时的已知限制
--------------------------------
- Scratch 官方素材库（造型/声音/背景/精灵库的图片和声音）来自
cdn / assets.scratch.mit.edu 等外部服务器，离线时加载不出来；
自己新建、画图、录音、导入本地文件的项目不受影响。
- 从 extensions.turbowarp.org 在线加载的扩展、云变量、在线项目页
（scratch.mit.edu / turbowarp.org 的项目）离线时同样不可用。
- 这是原站的限制，任何离线镜像都一样，不是镜像缺文件。

--------------------------------
技术备注
--------------------------------
- sw.js 已替换成“只跳过等待并清掉全部缓存”的短桩，不会被原站的
service worker 缓存劫持。
- 编辑器 JS 内部的 webpack 公共路径写的是根路径 "/"，所以必须把
本文件夹当服务器根目录打开（按上面方法做就是根目录，没问题）；
不要把整个文件夹塞到某个网站的子目录下访问。
- 原项目：TurboWarp（开源，https://github.com/TurboWarp/），
本镜像仅供个人离线使用。

============================================================
初见专属版 · 新增内容（by first light）
============================================================
1. 黑白主题（blackwhite.css，重写版）：菜单纯黑、积木白底黑边黑字。
   不想用时：点左下角工具条或灵动岛里的“主题”按钮，一键切回原版彩色。
2. 灵动岛（dynamic-island.js）：顶部中央的小药丸，显示时间和状态，
   点开有主题/截图/调试台/全屏四个快捷按钮。
3. 专属工具条（chujian-tools.js）：左下角，主题开关、舞台截图(PNG)、
   FPS 帧率显示、全屏、Ciallo 欢迎牌重现。
4. 彩虹调试台（logger.js）：沿用你原来的那份，顶部眼睛按钮开关，
   顶部菜单里原生的“插件（Addons）”入口已做路径修复，点它会打开本地的插件设置页；彩虹调试台用顶部眼睛按钮开关。
5. 官方素材库离线化（library-assets/，共 1306 个文件）：
   sw.js 会拦截发往 Scratch 素材 CDN 的请求，改从本地文件夹取，
   所以断网时角色/造型/声音/背景库也能打开。
   【重要】第一次打开 editor.html 后先刷新一次页面，
   让 sw.js 接管，之后再断网用，素材库才完整。
6. 标题已改成“初见的 TurboWarp ^_^”，进门有专属欢迎牌（关掉不再弹）。

仍然离线用不了的：在线扩展库（extensions.turbowarp.org）、
云变量、用 ID 打开 Scratch 在线项目——这些必须联网，和镜像无关。

7. 路径修复 v2（chujian-navfix.js）：MT 管理器预览用的是拦截式假域名，
   整页跳走或刷新，请求就再也回不来，这是 /editor、/addons 跳完就“不存在”的根源，
   光靠补文件治不好。所以改成釜底抽薪：点原生“插件”入口时不再整页跳转，
   而是在编辑器里弹出浮层打开本地插件页（还是官方那页），关掉就回编辑器，
   全程不离开编辑器页；插件设置改完点“关闭”就直接生效，不用刷新。
   另外 editor/index.html 跳转页保留，用正经本地服务器时刷新到 /editor 也能自动回来。
   最稳的打开方式仍是：在文件夹里用 Termux 跑 python -m http.server，
   再访问 localhost，在那边刷新、跳转都不会出问题。

8. 猫积木（cat-blocks）已设为默认开启：第一次打开编辑器时自动启用，
   积木会长猫耳朵。以后在插件设置里关掉的话，这个默认不会再强行打开。
9. 灵动岛升级：展开后第二排有 插件设置 / 运行（绿旗）/ 停止 / 纯净模式
   （把所有悬浮窗藏 5 秒，截图录屏不碍事），底部还有日期和实时 FPS。

10. 主题两档：黑白 / 原版彩色，灵动岛或工具条的“主题”按钮切换，选择会记住。
11. 离线扩展包（extensions-mirror/，223 个文件）：扩展库列表、104 个扩展
    本体和图标都已镜像，sw.js 会把 extensions.turbowarp.org 的请求转到本地，
    断网也能逛扩展库、加扩展。例外：人脸感应扩展的模型文件在别的 CDN 上，
    那个扩展仍需联网；另外扩展里的云变量、联网请求类功能本身就要网。
    （和素材库一样，第一次打开后先刷新一次让 sw 接管。）
12. 作品自动备份（chujian-backup.js）：工具条有“备份/恢复”按钮，
    编辑器开着时每 3 分钟自动存一份到浏览器本地（最多 5 份），
    手滑关页面/删错了可以从“恢复”里挑一份回来。备份只存这台设备这个浏览器里。

============================================================
版本切换（v6 合并版）
============================================================
以前每个版本一个包，太占地方。现在改成一个包带五个版本，
编辑器本体、素材库、扩展库只存一份，版本之间只是功能开关不同：
  v1 原版镜像：纯官方
  v2 初见经典：黑白主题 + 欢迎牌 + 彩虹调试台
  v3 进阶：v2 + 工具条 + 灵动岛 + 路径修复
  v4 猫猫：v3 + 猫积木默认开启
  v5 完全体：v4 + 作品自动备份（默认就是这个）
打开根目录的 index.html 可以选版本进入；
进了编辑器，点工具条上的“版本 vX”按钮（v1/v2 在右下角）也能随时换，
换完自动刷新生效。旧的那几个分开的版本包可以删了，留这一个就够。
