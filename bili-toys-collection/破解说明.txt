《B 站 Toy 合集 · 压缩+破解最终版》破解说明
================================================

本文件记录本版对每个 Toy 做的真实本地文件改动（不是改标题糊弄）。
所有被修改文件的原始版本都备份在构建工作目录的 backup/ 下；
所有改过的 JS 均通过 node --check 语法校验；改动均为“数据/门控判定”层面，
不改游戏逻辑流程，不影响启动。

（按用户要求，最终包不含，原件完整版仍保留）
- 节奏术力口（toy-rhythm-vocaloid）
- 驾考宝典（toy-jiakao-baodian，Unity WebGL；逻辑编译在 wasm/data 中，
包内没有可改的配置层，本就未破解，现按要求直接排除）

================================================
一、已破解（5 个）
================================================

1) 大狗大狗叫叫叫（toy-dagou-tap）—— 投币解锁项全开
改动文件：main.js
· toyCloudState 初始值 sfxUnlocked: false → true
· 云端核验失败的 catch 分支里 sfxUnlocked = false → true（防回滚保险）
效果：原本需要 B 站「充电/投币核验」才解锁的内容默认解锁——
叮咚鸡、哈基米两套音效包，以及哈基米帝皇皮肤。
说明：离线时核验函数本身就会提前返回、不重置该标记，两处改动双保险。

2) 基米斗模拟器 2.0（toy-jimi-simulator）—— 全部小猫解锁
改动文件：game.js（共 4 处）
· isCatUnlocked() 函数体改为恒 return true（唯一解锁判定入口）
· 初始 state.unlocks {follow, coin} 改为 true
· 读取旧存档时 unlocks.follow / unlocks.coin 强制写 true
· refreshUnlocks 中“未配置目标视频时重置 coin 解锁”的条件改为永假
效果：耄耋（关注解锁）、丑橘、香蕉猫（投币解锁）开局即全部可选。

3) 万梗捏（toy-mememash）—— 全梗 + 超软手感解锁
改动文件：assets/index-DLjX-ntf.js
· 判定函数 $d() 改为恒真（$d=()=>!0）
背景：游戏自带“本地预览全解锁”逻辑——在 localhost/file:// 打开时
所有梗和「超软」手感预设自动解锁，但用局域网 IP 在手机 MT 管理器里
预览时判定失效。本改动让全解锁在任何打开方式下都生效。

4) 鲸鱼娘养成计划（toy-xiaojingyu）—— 功能/时装全解锁 + 资金拉满
改动文件：3 个
· js/features/feature_unlock.js：meets() 首行 return true
—— 该函数是所有“版本/好感里程碑”门控的统一判定（功能按钮、
全部时装、街机小游戏都经 WhaleCare.refreshUnlocks 调用它），
恒真后全部解锁。
· js/features/follow_outfit.js：owned() 首行 return true
—— “关注/三连”时装的拥有判定，恒真后可直接穿戴。
· js/game_cfg.js：INIT_FUNDING 1200000 → 999999999（新游戏初始资金）
未改：版本 V1→V5 推进本身是核心玩法流程（强制跳版会破坏状态机），未动；
好感/工资等数值随玩法自然增长。

5) 合成小潮 team（toy-hecheng-xiaochao）—— 得分/掉落/金币强化
改动文件：2 个（其中一个是作者自留的作弊配置文件 extraSettings.js，
index.html 本就会加载它）
· src/extraSettings.js：extraScore 1 → 100
—— 每次合成得分 = 水果编号 + extraScore，得分涨幅大幅提高。
· src/extraSettings.js：随机掉落水果范围上限 5 档 → 11 档
—— 掉落池从最低 5 档扩到全部 11 档（葡萄…西瓜），更容易合出大水果。
· src/project.js：金币默认值 0 → 999999（两处：存档构造与兜底赋值）
未改：extraSettings.js 里的 wuDi（无敌）开关游戏自带且默认就是 true，
保持原样未动。

================================================
三、本版的压缩说明（有损，重要）
================================================
· 音频：mp3/ogg 重编码到 64k；wav 降采样到 22050Hz 单声道。音质有损。
· 图片：jpg 以 -q:v 9 重编码；png 用 pngquant 有损量化（不改变尺寸）。
画质有损，仔细看会有色带/噪点。
· 媒体文件总体积：54.9MB → 17.6MB（共 336 个文件，334 个变小）。
· 提醒：合成小潮的 74 张 PNG 图集经校验尺寸与原图完全一致；
另有 72 张 Cocos/Unity 图集类 PNG 被有损量化（尺寸不变），带 alpha 的
图集边缘理论上可能出现轻微 artifacts，如发现贴图边缘异常，
可对照完整版原件替换对应文件。
· 视频、代码、数据文件（含 WebGL 的.data/.wasm）一律未动。
· 鲸鱼娘的大量.webp 图片不在本次压缩范围内，保持原样。
