游戏介绍

  • 捏个世界 是一款像素风物理沙盒游戏
  • 自由创造、实验、观察元素和生物的反应

基本操作（电脑）

  • 左键拖动：绘制元素
  • 右键拖动：平移世界
  • 滚轮：缩放视图
  • Ctrl+Z / Ctrl+Y：撤销 / 还原

基本操作（移动）

  • 单指拖动：绘制元素
  • 双指拖动：平移世界
  • 双指捏合：缩放视图
  • 长按元素：查看属性

灾难系统

  • 无 / 龙卷风 / 台风 / 沙尘暴
  • 地震 / 陨石雨 / 火山爆发 / 洪水
